## What this project is

"The Storm Breaks": a text-driven grand-strategy game for history classrooms. The player
types natural-language orders; LLM agents return a narrative plus JSON **actions**; only
`server/engine.js` validates and applies actions; a D3 map and indicator panels render the
result; a teacher agent compares the alternate timeline with real history.

Stack: Node ≥ 18.17 (ES modules), Express 5, dotenv, vanilla JS + D3/topojson (bundled),
DeepSeek by default via any OpenAI-compatible API.

## How to work on it safely

1. **Only `server/engine.js` changes game state.** Agents, MCP and the frontend go through
   `applyActions()` or the REST API.
2. **Keep the engine scenario-agnostic.** Never import a scenario file directly into
   `engine.js`, `agents.js` or `mock.js`. Resolve everything through
   `getScenario(state.scenarioId)` from `server/data/scenarios/index.js`.
3. **Every new capability is an action type**: add it to `ACTION_TYPES` and `APPLY` in
   `engine.js`, describe it in `actionSpec()` in `agents.js`, document it in
   `docs/ACTIONS.md`, and add a test.
4. **Report determinism**: `server/report.js` owns the metrics and the weighted overall
   score. The LLM may only return per-rubric scores and prose.
5. **Offline mode must keep working.** If an agent's JSON shape changes, update
   `server/mock.js` (including `mockReport`).
6. **Safety rules** (`SAFETY` in `agents.js`) are not optional: atrocities are never
   playable, the Holocaust is taught accurately, invented dialogue is never a real quote.
7. **Escape all text** with `esc()` from `public/js/panels.js`.

## Run and verify

```bash
npm install
npm start          # http://localhost:3000
npm test           # engine tests, no AI needed
node --check server/engine.js   # quick syntax check
```

To test without spending API calls, run the server from a directory with no `.env` (e.g.
the temp dir) so it uses offline demo mode, or clear `LLM_API_KEY`.
